# 🚛 Diesel Price Predictor
**A data analysis project to predict diesel fuel prices in Sweden using historical market data and trend analysis.**  
> 📊 Built during my studies in Data Science & AI Development at EC Utbildning. This project analyzes real-world fuel pricing trends from Blocket.se and builds a predictive model to forecast diesel price movements.  
🔗 **Project Report:** [View Full PDF Report](https://github.com/George-glor/DieselPricePredictor/blob/main/DieselPricePredictor_GeorgeGlor.pdf)  
📁 **Repository:** [github.com/George-glor/DieselPricePredictor](https://github.com/George-glor/DieselPricePredictor)

## 🧠 About the Project
This project analyzes diesel fuel prices across Sweden using publicly available data from **Blocket.se**, one of Sweden’s largest marketplaces. The objectives were to:
- Understand historical pricing trends
- Identify regional and seasonal patterns
- Build a predictive model to forecast future diesel prices  
It demonstrates skills in **data scraping, cleaning, visualization, statistical analysis, and regression modeling** using Python and R.

## 🔍 Key Features
✅ **Data Collection:** Scraped and cleaned real diesel price listings  
✅ **Exploratory Data Analysis (EDA):** Visualized trends by region, time, and seller type  
✅ **Price Prediction:** Built a regression model to forecast price changes  
✅ **Insights & Reporting:** Identified key factors affecting diesel prices  
✅ **Full Documentation:** Includes methodology, assumptions, and conclusions

## 🛠️ Tech Stack
| Tool | Purpose |
|------|--------|
| **Python** | Data scraping & preprocessing |
| **Pandas, NumPy** | Data manipulation |
| **Matplotlib, Seaborn** | Data visualization |
| **Scikit-learn** | Regression modeling |
| **R Programming** | Statistical analysis & forecasting |
| **Jupyter Notebook** | Interactive analysis |
| **PDF Report** | Documentation of findings |

## 📈 Key Findings
- Diesel prices vary significantly by **region** (higher in rural areas)  
- Clear **seasonal trends** observed (prices rise in winter)  
- **Supply-demand imbalances** impact local pricing  
- Model achieved **~85% accuracy** in short-term predictions (RMSE evaluation)
